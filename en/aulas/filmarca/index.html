Lesson 5 · 18 min

Brand film from your own site

So far the video became a page. Now the reverse path: the page becomes a video. filmarca (ARCKHÉ) reads the colors, fonts, logo, copy, and screenshots of a site and builds a brand film in HyperFrames. You run the whole path against the kit's page without calling any model, using filmarca's own template scenes, and then you put the film on the page.

Start the lesson

In this lesson you will

  1. 1The DNA: what filmarca reads from a site and where it gets it wrong
  2. 2A script built from facts on the page and the six template scenes (opening, title, number, screenshot, list, call to action)
  3. 3Local render, no model: the rehearsal that proves the path before you spend anything
  4. 4The film back on the page, without weighing down the first paint

Goal: read the kit site's DNA with filmarca and render a brand film with template scenes, without calling a model.

02 · Install filmarca

In a rehearsal folder, at the tested commit. The project's npm test runs without a model.

Terminal · clone, install, and test
E=${TMPDIR:-/tmp}/ensaio-sites/a5; rm -rf "$E"; mkdir -p "$E"; cd "$E"
git clone -q https://github.com/linnoff88-dev/filmarca && cd filmarca && git checkout -q 0c0356c; echo "clone: $?"
npm ci --no-audit --no-fund > npm.log 2>&1; echo "npm ci: $?"
node -p "'hyperframes ' + require('hyperframes/package.json').version + ' · playwright ' + require('playwright/package.json').version"
npx playwright install chromium > pw.log 2>&1; echo "chromium: $?"
npm test 2>&1 | grep -E "^ℹ (pass|fail)"

The 5 tests prove that a broken scene is rejected and that the template scene takes its place.

03 · Read the DNA of the kit's page

The kit's server serves the lens page; filmarca reads it the way it would read any site.

Terminal · DNA of the kit's site
K=~/projetos/formacao-cARCKHÉ-ia-sites-v72/kit
E=${TMPDIR:-/tmp}/ensaio-sites/a5; cd "$E/filmarca"
node "$K/scripts/servir.mjs" "$K/site" > "$E/url.txt" & S=$!
until U=$(cat "$E/url.txt") && [ -n "$U" ] && curl -s -o /dev/null "$U"; do sleep 0.3; done
node bin/filmarca.mjs dna "$U" --out "$E/filme"; echo "dna: $?"
kill $S
ls "$E/filme/assets"

Note the primary color: #e2a23b is the yellow of the motion switch (Parado / Ligado), not the brand's accent. The DNA reads what shows on screen. Check marca.json before you generate, and fix by hand whatever is wrong.

04 · Render without a model

A script built from facts on the page (kit/filmarca/roteiro.json) and filmarca's template scenes in place of the scenes step.

Terminal · template scenes, render, and check
K=~/projetos/formacao-cARCKHÉ-ia-sites-v72/kit
E=${TMPDIR:-/tmp}/ensaio-sites/a5; cd "$E/filmarca"
export HYPERFRAMES_NO_TELEMETRY=1
cp "$K/filmarca/roteiro.json" "$E/filme/"
node "$K/scripts/cenas-modelo.mjs" . "$E/filme"
node bin/filmarca.mjs render "$E/filme" --formatos 16x9 --rascunho; echo "render: $?"
python3 "$K/scripts/conferir-video.py" "$E/filme/renders/aurora-35-pt-16x9.mp4" 17.5 1920x1080; echo "saída: $?"

05 · With the model from your subscription, and back on the page

The real step swaps the hand-written script and the template scenes for the director and the scenes animated by the model. Then the MP4 goes into the page.

With the model · script, scenes, and render

node bin/filmarca.mjs roteiro <pasta-do-filme> --pedido "filme de apresentação da lente para a página" --motor claude
node bin/filmarca.mjs cenas <pasta-do-filme> --motor claude
node bin/filmarca.mjs render <pasta-do-filme> --formatos 16x9,9x16 --rascunho
