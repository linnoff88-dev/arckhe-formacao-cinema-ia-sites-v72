Aula 8 · 20 min

Seu site: uma página de produto com rolagem cARCKHÉtográfica publicada

Hora de juntar tudo numa página sua. Você parte do modelo do kit, troca a foto e os textos pelos do seu produto, refaz os dois filmes, passa no portêo de quatro conferências e publica no GitHub Pages. O mesmo verificador que rodou na sua máquina roda contra a URL pública: é ele que diz que está no ar.

02 · Do modelo à sua página, com o portêo

O ensaio troca a lente de frente pela lente deitada; no seu, troque pela foto do seu produto e reescreva os textos do index.html.

Terminal · montar a página e passar no portêo
K=~/projetos/formacao-cARCKHÉ-ia-sites-v72/kit
E=${TMPDIR:-/tmp}/ensaio-sites/a8; rm -rf "$E"; mkdir -p "$E"
# o seu site começa como cópia do modelo; troque a foto do produto pela sua (aqui: a lente deitada)
cp -r "$K/site" "$E/meu-site"; rm -f "$E/meu-site"/erro-*.html
bash "$K/scripts/clipe.sh" "$K/exemplos/lente2.jpg" "$E/h.mp4" 6 1.0 1.3
bash "$K/scripts/clipe.sh" "$K/exemplos/lente2.jpg" "$E/v.mp4" 6 1.0 1.3 1080x1920
bash "$K/scripts/quadros.sh" "$E/h.mp4" "$E/meu-site/frames" 1024 6
bash "$K/scripts/quadros.sh" "$E/v.mp4" "$E/meu-site/frames-v" 600 8
bash "$K/scripts/portao.sh" "$E/meu-site"; echo "saída: $?"
Arquivo · kit/scripts/portao.sh
#!/usr/bin/env bash
# portao.sh — o portêo final da página: 4 conferências, uma por vez, sem modelo e sem serviço pago.
#   1. peso       visitante mais pesado ≤ ORCAMENTO MB (padrêo 6) e primeira pintura ≤ 0,5 MB
#   2. computador 1366×768: rolagem em 0 %, 50 % e 100 % com o quadro certo e tela pintada
#   3. celular    390×844 em pé: filme vertical (frames-v/), sem transbordo
#   4. reduzir    com "reduzir movimento": o filme fica parado
# Uso: bash portao.sh <pasta-do-site>          (ORCAMENTO=8 bash portao.sh … muda o teto)
set -uo pipefail
K=$(cd "$(dirname "$0")/.." && pwd)
SITE=$(cd "$1" && pwd)
T=$(mktemp -d); trap 'kill $S 2>/dev/null; rm -rf "$T"' EXIT
node "$K/scripts/servir.mjs" "$SITE" > "$T/url" & S=$!
until U=$(cat "$T/url" 2>/dev/null) && [ -n "$U" ] && curl -s -o /dev/null "$U"; do sleep 0.3; done
ok=0
python3 "$K/scripts/peso.py" "$SITE" --orcamento "${ORCAMENTO:-6}" --inicial 0.5 > "$T/1" && ok=$((ok+1)) && echo "1 peso: OK" || { echo "1 peso: FALHA"; grep -E "ACIMA" "$T/1"; }
for n in "2 computador:" "3 celular:--celular" "4 reduzir:--reduzir"; do
  rot=${n%%:*}; op=${n#*:}
  node "$K/scripts/verificar.mjs" "$U" $op > "$T/v" && ok=$((ok+1)) && echo "$rot: OK" || { echo "$rot: FALHA"; grep "^FALHA" "$T/v"; }
done
echo "PORTêO: $ok/4 $([ $ok -eq 4 ] && echo OK || echo FALHOU)"
[ $ok -eq 4 ]

03 · Publicar e verificar no ar

Um repositório público com a página na raiz, GitHub Pages na branch main. Depois, o verificador contra a URL pública.

Uma vez · publicar a pasta no GitHub Pages
cd <pasta-do-seu-site>
git init -b main && git add . && git commit -m "minha página com filme na rolagem"
gh repo create <seu-usuario>/<nome-do-repo> --public --source . --push
gh api -X POST repos/<seu-usuario>/<nome-do-repo>/pages -f 'source[branch]=main' -f 'source[path]=/'
Terminal · verificar uma página publicada
K=~/projetos/formacao-cARCKHÉ-ia-sites-v72/kit
curl -s -o /dev/null -w "%{http_code}\n" https://linnoff88-dev.github.io/
node "$K/scripts/verificar.mjs" https://linnoff88-dev.github.io/ echo "saída: $?"

04 · Prática

A sua página, do modelo ao ar.

E1 · Portêo no ensaio

10 min

Rode "montar a página e passar no portêo".

Pronto quando: PORTêO: 4/4 OK e saída: 0.

E2 · A sua página

60 min

Copie kit/site para uma pasta sua, apague as cópias erro-*.html, troque a foto (clipe.sh nos dois formatos), refaça os quadros, reescreva os textos do index.html só com fatos do seu produto e rode o portêo de texto da aula 6 e o portao.sh.

Pronto quando: O portêo de texto responde texto limpo e o portao.sh responde PORTêO: 4/4 OK com saída: 0.

E3 · No ar

15 min

Publique pelo bloco "publicar a pasta no GitHub Pages" e rode o verificador com a sua URL.

Pronto quando: curl -s -o /dev/null -w "%{http_code}" [sua URL] responde 200 e o verificador responde OK: 3 de 3 posições com saída: 0.
