Clase 8 · 20 min

Tu sitio: una página de producto con scroll cinematográfico publicada

Es hora de juntar todo en una página tuya. Partes de la plantilla del kit, cambias la foto y los textos por los de tu producto, rehaces las dos películas, pasas la puerta de control de cuatro verificaciones y publicas en GitHub Pages. El mismo verificador que corrió en tu máquina corre contra la URL pública: es él quien dice que está en línea.

Comenzar la clase

En esta clase vas a

  1. 1La plantilla del kit como punto de partida, con tu foto y tu texto
  2. 2La puerta de control 4/4: peso, computador, celular y reducir movimiento
  3. 3Publicar en GitHub Pages y verificar la URL pública
  4. 4Tu plan con fechas y el mapa de toda la formación

Objetivo: armar tu página a partir de la plantilla del kit, pasar la puerta de control 4 de 4 y publicar en GitHub Pages.

02 · Del modelo a tu página, con la puerta de control

El ensayo cambia la lente de frente por la lente acostada; en el tuyo, cámbiala por la foto de tu producto y reescribe los textos del index.html.

Terminal · montar la página y pasar la puerta de control
K=~/projetos/formacao-cinema-ia-sites-v72/kit
E=${TMPDIR:-/tmp}/ensaio-sites/a8; rm -rf "$E"; mkdir -p "$E"
# tu sitio empieza como copia del modelo; cambia la foto del producto por la tuya (aquí: la lente acostada)
cp -r "$K/site" "$E/meu-site"; rm -f "$E/meu-site"/erro-*.html
bash "$K/scripts/clipe.sh" "$K/exemplos/lente2.jpg" "$E/h.mp4" 6 1.0 1.3
bash "$K/scripts/clipe.sh" "$K/exemplos/lente2.jpg" "$E/v.mp4" 6 1.0 1.3 1080x1920
bash "$K/scripts/quadros.sh" "$E/h.mp4" "$E/meu-site/frames" 1024 6

Archivo · kit/scripts/portao.sh
#!/usr/bin/env bash
# portao.sh — o portão final da página: 4 conferências, uma por vez, sem modelo e sem serviço pago.
#   1. peso       visitante mais pesado ≤ ORCAMENTO MB (padrão 6) e primeira pintura ≤ 0,5 MB
#   2. computador 1366×768: rolagem em 0 %, 50 % e 100 % com o quadro certo e tela pintada
#   3. celular    390×844 em pé: filme vertical (frames-v/), sem transbordo
#   4. reduzir    com "reduzir movimento": o filme fica parado
# Uso: bash portao.sh <pasta-do-site>          (ORCAMENTO=8 bash portao.sh … muda o teto)
set -uo pipefail
K=$(cd "$(dirname "$0")/.." && pwd)
SITE=$(cd "$1" && pwd)
T=$(mktemp -d); trap 'kill $S 2>/dev/null; rm -rf "$T"' EXIT
node "$K/scripts/servir.mjs" "$SITE" > "$T/url" & S=$!
until U=$(cat "$T/url" 2>/dev/null) && [ -n "$U" ] && curl -s -o /dev/null "$U"; do sleep 0.3; done
ok=0
python3 "$K/scripts/peso.py" "$SITE" --orcamento "${ORCAMENTO:-6}" --inicial 0.5 > "$T/1" && ok=$((ok+1)) && echo "1 peso: OK" || { echo "1 peso: FALHA"; grep -E "ACIMA" "$T/1"; }
for n in "2 computador:" "3 celular:--celular" "4 reduzir:--reduzir"; do
  rot=${n%%:*}; op=${n#*:}
  node "$K/scripts/verificar.mjs" "$U" $op > "$T/v" && ok=$((ok+1)) && echo "$rot: OK" || { echo "$rot: FALHA"; grep "^FALHA" "$T/v"; }
done
echo "PORTÃO: $ok/4 $([ $ok -eq 4 ] && echo OK || echo FALHOU)"
[ $ok -eq 4 ]

03 · Publicar y verificar en línea

Un repositorio público con la página en la raíz, GitHub Pages en la rama main. Después, el verificador contra la URL pública.

Una vez · publicar la carpeta en GitHub Pages
cd <carpeta-de-tu-sitio>
git init -b main && git add . && git commit -m "mi página con película en el scroll"
gh repo create <tu-usuario>/<nombre-del-repo> --public --source . --push
gh api -X POST repos/<tu-usuario>/<nombre-del-repo>/pages -f 'source[branch]=main' -f 'source[path]=/'
Terminal · verificar una página publicada
K=~/projetos/formacao-cinema-ia-sites-v72/kit
curl -s -o /dev/null -w "%{http_code}\n" https://inematds.github.io/formacao-cinema-ia-sites-v72/kit/site/
node "$K/scripts/verificar.mjs" https://inematds.github.io/formacao-cinema-ia-sites-v72/kit/site/; echo "saída: $?"

60 min

15 min

Listo cuando: curl -s -o /dev/null -w "%{http_code}" [tu URL] responde 200 y el verificador responde OK: 3 de 3 posições con saída: 0.
